# Flask Script Manager

Flask Script Manager — это простое веб-приложение, которое позволяет управлять вашими скриптами, аналогично systemd. Вы можете запускать, останавливать и просматривать логи скриптов, а также настраивать их автозапуск.

## Структура проекта

```
flask-script-manager
├── app.py                # Главная точка входа в приложение Flask
├── scripts               # Каталог, содержащий управляемые скрипты
│   └── example_script.py # Пример скрипта, который можно управлять
├── static                # Каталог для статических файлов (CSS, JS и т.д.)
│   └── style.css         # CSS-стили для веб-интерфейса
├── templates             # Каталог для HTML-шаблонов
│   ├── index.html       # Основной HTML-шаблон для веб-интерфейса
│   └── logs.html        # Шаблон для отображения логов скриптов
└── README.md             # Документация проекта
```

## Установка

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/NextStepDevOfficial/WebScriptManager
   cd flask-script-manager
   ```

2. Создайте виртуальное окружение:
   ```
   python -m venv venv
   source venv/bin/activate  # Для Windows используйте `venv\Scripts\activate`
   ```

3. Установите необходимые пакеты:
   ```
   pip install Flask
   ```

## Использование

1. Запустите приложение:
   ```
   python app.py
   ```

2. Откройте веб-браузер и перейдите по адресу `http://127.0.0.1:5000`.

3. Используйте веб-интерфейс для управления скриптами:
   - Запускайте и останавливайте скрипты.
   - Просматривайте логи выполненных скриптов.
   - Включайте или отключайте автозапуск для скриптов.
